The curriculum

Five machines, and the order that makes them cumulative.

The factory is an arrangement of specialized machinery. These five pages teach the machines — one each — and they are ordered so that every page can assume the one before it. Every one ends in a falsification table: the claims it makes, the command that would disprove each one, and what that command should print. Run them.

The contract every one of these pages signs. Each ends with a table naming the claims it makes, the command that exercises each claim, what you should see, and the specific observation that would kill it. Commands carry their directory — run them from the repository root and they fail with MODULE_NOT_FOUND, which on a page whose contract is run the command would be the worst available defect. Counts are derived by the suites that produce them and are never hand-typed, because a published count and a printed count drifted apart exactly once and that was enough.
Two figures were removed from a published draft for lacking a primary source, and the composition masterclass says so in its own text rather than quietly correcting them. A third page's hand-typed cell count disagreed with its own data array and now derives the number instead. These are not incidental — they are the same discipline the falsification tables enforce, applied to the pages themselves.
